# Dataset provenance

`Iris.csv` is version 1 of the Kaggle dataset [Iris.csv by saurabh00007](https://www.kaggle.com/datasets/saurabh00007/iriscsv/versions/1). The accompanying Kaggle metadata declares the dataset license as [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

The file contains 150 flower records with four measurements and the `Species` label. The `Id` field is preserved in the source CSV but excluded from model inputs.
